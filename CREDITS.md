# 🏛️ Credits & Open Source Attributions

This document acknowledges and expresses gratitude to the open-source projects, thinkers, and software architects whose ideas, tools, and methodologies influenced features across the `muse-skills` ecosystem.

## Attributions & Influences

- **[Daniel Miessler](https://github.com/danielmiessler)** ([LifeOS](https://github.com/danielmiessler/LifeOS)): Influenced personal intent engineering, the strategic review cycle in `periodic-retreat`, and foundational concepts behind personal compass and assistant identity.
- **[Steve Schoger & Adam Wathan](https://refactoringui.com)** ([Refactoring UI](https://refactoringui.com)): Influenced the visual hierarchy heuristics, tactical typography scales, and spacing decision trees in `refactor-ui` and `designscope`.
- **[Linus Torvalds & Linux Kernel Community](https://git.kernel.org)** ([Linux](https://git.kernel.org)): Influenced the uncompromising code quality invariants, anti-overengineering rules, and "taste" criteria in `code-review`.
- **[Anthony Fu](https://github.com/antfu)** ([UnoCSS](https://github.com/unocss/unocss)): Influenced the high-performance utility-first styling architecture, Wind 4 presets, and instant compilation standards in `new-project` and `webdev`.
- **[Fred K. Schott & Astro Team](https://github.com/withastro)** ([Astro](https://github.com/withastro/astro)): Influenced the content-first architecture, zero-JS baseline philosophy, and modern template scaffolding in `new-project`.
- **[Jarred Sumner & Bun Team](https://github.com/oven-sh)** ([Bun](https://github.com/oven-sh/bun)): Influenced the ultra-fast test execution runner, native TypeScript runtime tooling, and rapid installation scripting across all skills.
- **[Biome Team](https://github.com/biomejs)** ([Biome](https://github.com/biomejs/biome)): Influenced zero-dependency fast linting and formatting standards across the agency toolchain.
- **[Matt Perry](https://github.com/mattgperry)** ([Motion](https://github.com/motiondivision/motion)): Influenced the declarative physics-based animation primitives and timing curves codified in `animate`.
- **[GreenSock](https://greensock.com)** ([GSAP](https://greensock.com/gsap/)): Influenced scroll-driven storytelling, timeline sequencing, and hardware-accelerated choreography in `animate`.
- **[W3C Design Tokens Community Group](https://design-tokens.github.io/community-group/format/)** ([DTCG Specification](https://design-tokens.github.io/community-group/format/)): Influenced the OKLCH token architecture, fluid clamp scales, and token format conventions in `design` and `brand`.
- **[Medusa Commerce Team](https://github.com/medusajs)** ([Medusa](https://github.com/medusajs/medusa)): Influenced the sovereign, headless e-commerce backend scaffolding and modular commerce architecture in `new-project`.
- **[OpenCode, Antigravity, Cursor, & Claude Code Teams](https://github.com)**: Influenced the multi-harness slash command export engine, progressive disclosure DOX patterns, and universal agent interoperability in `export-commands` and `updateagents`.
