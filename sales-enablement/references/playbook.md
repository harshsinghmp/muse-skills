# playbook — Sales playbook: how reps win consistently.

## Scope

- The buyer, stages, and the offers/demos the team sells.
- Real deal history (win/loss, calls, objections).
- Team size and rep experience.

## Deliverable

A playbook: the sale stages, per-stage scripts and asks, disqualify rules, pitch paths by buyer type, and objection callouts — so every rep sells the same honest story.

## Procedure

1. Map the sale: stages from first contact to close, with the ask at each.
2. Capture real deal history: what wins, what stalls, what disqualifies — from win/loss, not guesswork.
3. Write per-stage scripts: opening, discovery, demo ask, close attempt.
4. Define disqualify rules (budget, fit, timing) so reps stop chasing bad deals.
5. Build pitch paths by buyer type (champion vs economic buyer vs technical).
6. Cross-link the objection handbook and demo so the playbook is one system.
7. Keep the voice consistent with positioning and pricing set in `growth`.

## Quality gate

- [ ] Stages with a concrete ask each.
- [ ] Scripts grounded in real win/loss, not invented friction.
- [ ] Disqualify rules explicit.
- [ ] Pitch paths by buyer type present.
- [ ] Consistent with `growth` positioning/pricing and the other enablement assets.

## Routing

- Deal-stage changes → `ops` (milestone).
- Positioning/pricing inputs → `growth`.
