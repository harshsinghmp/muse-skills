# 🎨 Brand, Voice & Presentation

## Core Tone & Voice
- Direct, precise, technical, and authoritative.
- Zero boilerplate, no introductory meta-announcements, and no ungrounded claims.

## Documentation & Presentation Standards
- Clean GitHub-flavored Markdown with structured headings, tables, and mermaid diagrams.
- Clickable relative markdown links for all referenced documents and files.
- Visual tokens and detailed design assets follow `./brand/BRAND_GUIDELINES.md`.
